# Object-Oriented Programming in Java

Lab work from the *Objektno orijentisane tehnologije* (Object-Oriented Technologies) course, built up week by week.

## Contents

- **`ObjektnoIM133/src/geometry`**: a shape hierarchy (`Point`, `Line`, `Rectangle`, `Circle`, `Donut`) built on an abstract `Shape` class and a `Moveable` interface. It covers inheritance, polymorphism, `equals`/`compareTo` and encapsulation.
- **`src/drawing`**: a Swing drawing app. You draw, select and modify shapes on a canvas, using a dialog per shape type.
- **`src/stack`**: a Swing app that manages a stack of circles through dialogs.

## Stack

- Java, Swing / AWT
- IntelliJ IDEA and Eclipse project files

## Running

Open the project in IntelliJ IDEA and run `drawing.DrawingApp` or `stack.StackApp`.
